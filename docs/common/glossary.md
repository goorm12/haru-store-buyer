# 하루상점 — 용어 정의 및 표기 기준

- 작성일: 2026-10-14
- 적용 범위: 요구사항, 화면 문구, 기획·설계 문서, API 설명
- 서비스명: 하루상점 / Haru Store
- 영문 식별자는 구현 시 사용할 권장안이며 기술 스택·데이터 구조 확정을 의미하지 않는다.

## 1. 용어 통일

| 기존·혼용 표현 | 표준 용어 | 영문 권장 | 정의 |
| --- | --- | --- | --- |
| 가게, 매장, 샵 | 상점 | Store | 판매자가 운영하는 판매 공간. 상품·공구·예약의 관리 단위 |
| 사장님, 점주 | 판매자 | Seller | 상점을 소유하고 공구와 예약을 운영하는 사용자 |
| 손님, 고객 | 구매자 | Buyer | 상품을 보고 예약·수령하는 사용자 역할. 결제 완료 여부와 무관 |
| 회원, 계정 사용자 | 회원 | User | 서비스 계정을 가진 사람. 구매자·판매자는 역할로 구분 |
| 비로그인 사용자 | 비회원 | Guest | 로그인 없이 상점·상품을 조회하는 사용자 |

| 공구 | 공동구매 | Group Buy | 정해진 기간·조건으로 구매자를 모집하는 판매 방식 |

| 방문 수령, 찾아가기 | 픽업 | Pickup | 예약한 상점에서 상품을 직접 수령하는 행위 |

| 찜한 상점, 즐겨찾기 | 내 상점 | Saved Stores | 구매자가 저장한 이용 상점. 구매자 소유 상점을 의미하지 않음 |

## 2. 상점·판매자 관계

- 판매자 하나가 여러 상점을 운영할 수 있다.
- 상품·공구·예약·예약 가능 수량은 상점별로 독립 관리한다.
- 상점과 지점을 동의어로 쓰지 않는다. 지점은 물리적 운영 형태를 설명하는 용어다.
- 물리적 매장은 실제 방문 장소이고, 픽업 장소는 예약 상품을 수령할 주소다. MVP에서는 상점에 등록한 장소에서 픽업한다.
- 인플루언서는 향후 판매자 유형이며 별도 기본 역할을 만들기로 확정한 것은 아니다.
- 같은 카카오 계정이 구매자·판매자 역할을 함께 가진다. 판매자는 PC·모바일 웹, 구매자는 앱에서 같은 회원 시스템을 사용한다.
- 구매자 화면은 ‘내 상점’, 판매자 화면은 ‘운영 상점’으로 구분한다.

## 3. 상품·공구·예약 구분

| 개념 | 예시 | 기준 |
| --- | --- | --- |
| 상품 | 사과 1박스 | 구매 대상 물품과 판매 단위 |
| 공구 상품 | A상점의 10월 사과 공구 | 특정 회차의 가격·수량·예약 기간·픽업 가능일 포함 |
| 예약 | 사과 2박스, 10월 15일 픽업 | 구매자·상점·공구 상품·수량·날짜 연결 |
| 주문 | 온라인 구매 거래 | 향후 결제 도입 시 별도 정의. MVP 예약을 주문으로 혼용하지 않음 |

MVP에서는 상품 카탈로그와 공구 회차를 별도 엔티티로 분리할 필요가 없으며, 공구마다 별도 게시물로 등록한다. 같은 상품을 다른 상점이나 다음 회차에서 판매하면 별도 공구 상품이다.

‘공동구매’는 판매 방식이며, 최소 인원 달성 조건을 뜻하지 않는다. 최소 모집 인원·목표 달성 후 확정 기능은 현재 MVP 범위에 없다.

## 4. 날짜·수량 용어

| 용어 | 정의 |
| --- | --- |
| 예약 시작 일시 | 신규 예약 접수를 시작하는 시각 |
| 예약 마감 일시 | 해당 공구의 신규 예약 접수를 끝내는 시각 |
| 픽업 가능일 | 판매자가 수령 가능하도록 지정한 날짜 목록 |
| 픽업일 | 구매자가 예약에서 선택한 수령 날짜 |
| 픽업 운영시간 | 해당 장소에서 상품을 받을 수 있는 시간 범위 |
| 당일 접수 마감 | 오늘 픽업할 예약을 받을 수 있는 마지막 시각 |
| 변경 마감 | 구매자가 수량·픽업일을 변경할 수 있는 마지막 시각 |
| 취소 마감 | 구매자가 예약을 취소할 수 있는 마지막 시각 |
| 판매 단위 | 수량 1이 의미하는 단위. 예: 1박스, 1봉 |
| 총 예약 가능 수량 | 공구 전체가 받을 수 있는 수량 한도 |
| 남은 예약 가능 수량 | 한도에서 수량을 점유한 예약을 제외한 접수 가능 수량 |
| 준비 수량 | 특정 픽업일에 전달할 유효 예약의 수량 합계 |

예약 가능 수량을 실제 창고 재고와 같은 뜻으로 쓰지 않는다. 취소 수량은 반환하지만 픽업 완료·미수령 수량을 자동 반환하지 않는다. 변경·직접 취소는 픽업 전날 23:59까지이며 당일 불가하다. 직접 취소 제한 상품은 수량 감소도 불가하다.

## 5. 상태·행동 용어

| 대상 | 표준 상태 |
| --- | --- |
| 공구 상품 | 작성 중, 예약 예정, 예약 중, 접수 중단, 마감, 공구 취소 |
| 예약 | 예약 확정, 구매자 취소, 판매자 취소, 픽업 완료, 미수령 |
| 결제 | 미결제, 현장 결제 완료 |

- 접수 중단: 신규 예약·수량 증가 차단, 기존 예약 유지.
- 공구 취소: 해당 공구의 아직 픽업하지 않은 유효 예약 전체 취소.
- 구매자 취소: 구매자가 본인 예약을 전체 취소.
- 판매자 취소: 판매자 측 사유로 취소된 예약 상태. MVP에서는 공구 전체 취소 또는 사유·알림·이력을 남기는 개별 예약 취소로 발생한다.
- 픽업 완료: 판매자가 상품을 전달하고 수령 완료를 기록한 상태.
- 미수령: 판매자가 실제 확인 후 수령하지 않은 예약으로 처리한 상태.
- 픽업일 경과: 날짜에 따른 표시. 예약 상태가 아니며 자동 미수령을 의미하지 않음.
- 품절: 남은 예약 가능 수량이 0임을 안내하는 표시. 별도 확정 상태가 아님.
- 결제 완료와 픽업 완료를 혼용하지 않는다.
- 알림 내역은 앱에서 확인하는 안내이며, 푸시 알림은 단말에 보내는 전달 방식이다.

## 9. 추가 정책 용어

| 용어 | 정의 |
| --- | --- |
| 기본 상점 | 구매자가 직접 지정한 첫 진입 상점. 판매자 운영 상점과 구분 |
| 1인 최대 수량 | 같은 구매자가 같은 공구 상품에 예약할 수 있는 수량 한도. 기본 미설정 |
| 직접 취소 제한 | 구매자의 전체 취소와 수량 감소를 막는 공구 정책. 법정 권리 요청은 별도 처리 |
| 결제 방식 | 현장 결제 또는 향후 온라인 결제 |
| 수령 방식 | 픽업 또는 향후 배송 |
| 유효 예약 | 취소되지 않고 아직 완료·미수령 처리되지 않은 예약 |

같은 계정·역할별 화면과 사전 승인 없는 상점 개설을 확정했다. 픽업 알림은 전날 18시와 당일 시작 2시간 전이며, 당일 계산 시각이 08시 이전이면 08시로 조정하고 시작 시각 이상이면 생략한다.

- 개별 예약 취소: 판매자가 유효 예약 하나만 취소하는 행동. 공구 취소와 구분한다.
- 기록 정정: 잘못 입력한 픽업·결제 기록을 사유와 이력을 남겨 수정하는 행동. 실제 환불을 의미하지 않는다.
- 접수 중단 이후의 유효 픽업일: 공구가 유지하는 수령 날짜. 신규 접수 가능 여부와 별개로 기존 예약의 날짜 변경에 사용한다.


## 10. 최종 정책 용어

| 용어 | 확정 정의 |
| --- | --- |
| 사전 승인 없는 개설 | 필수 정보 입력 후 운영 가능. 사업자·연락처 인증 완료를 의미하지 않음 |
| 변경·직접 취소 마감 | 기존 픽업일 전날 23:59 한국 시간. 당일 00:00부터 제한 |
| 취소 후 재예약 | 접수 기간·픽업일·잔여 수량·개인 한도 내 새 예약 생성. 취소 기록은 보존 |
| 픽업 완료 후 재구매 | 같은 공구에서는 불가. 다음 공구는 별개 |
| 1인 한도 적용 수량 | 취소를 제외한 같은 공구의 예약 수량. 미수령은 제외하지 않음 |
| 계정 탈퇴 | 계정 접근 종료와 불필요 정보 파기. 법정 거래기록 보존과 구분 |
| 법정 분리 보관 | 법률에 따라 필요한 기록만 목적·기간·접근 권한을 정해 별도 보관 |

P01~P16은 확정 정책이다. 기술 식별자·화면 설계와 온라인 결제·배송 단계의 요구사항은 후속 작업으로 구분한다.

## 11. 공지·문의 용어

| 혼용 표현 | 표준 용어 | 정의 |
| --- | --- | --- |
| 게시판, 소식 | 상점 공지사항 | 판매자가 상점 소식·공구 예고·휴무 안내를 공개하는 별도 게시물 |
| 공지 반응 | 공지 댓글 | 구매자가 공개 공지에 남기는 글. 예약으로 인정하지 않음 |
| 공지 댓글 응답 | 판매자 답글 | 판매자가 공지 댓글에 남기는 답글 |
| 문의사항, 질문 | 상점 문의 | 구매자가 작성하고 작성자·해당 상점 판매자만 조회하는 비공개 문의 |
| 문의 댓글 | 문의 메시지·답변 | 문의 작성자와 해당 상점 판매자의 비공개 대화 |
| 전체 공지 알림 | 상점 공지 알림 | 새 공지 등록 시 해당 상점을 내 상점에 저장한 구매자에게 생성하는 안내 |

상점 문의와 플랫폼 신고·분쟁 처리 요청은 서로 다른 업무다. 플랫폼 관리자의 문의 본문 열람 권한을 자동 부여하지 않는다.
