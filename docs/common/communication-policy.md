# 하루상점 — 공지사항·댓글·비공개 문의 정책

- 버전: v1.1 / 반영일: 2026-10-14
- 상태: 아래 확정 정책은 사용자 승인 반영. 세부 설계 항목은 사업 정책 확정과 구분한다.

## 1. 확정 정책

| ID | 항목 | 확정 내용 |
| --- | --- | --- |
| C01 | 기능 구분 | 공지사항과 문의사항은 별도 목록·상세·작성 흐름으로 제공 |
| C02 | 공지 작성 | 해당 상점 판매자가 공구 예고·휴무·픽업 안내 등을 작성 |
| C03 | 공지 소통 | 구매자 댓글과 판매자 답글 지원. 댓글은 예약이 아님 |
| C04 | 문의 공개 범위 | 비공개. 작성자와 해당 상점 판매자만 본문·답변 조회 가능 |
| C05 | 문의 대화 | 작성자와 판매자만 메시지·답변 가능. 다른 구매자의 조회·대댓글 불가 |
| C06 | 수정·삭제 | 본인 글·댓글·답글·문의 메시지 수정·삭제 가능. 답변이 있다는 이유로 본인 수정·삭제를 막지 않음 |
| C07 | 새 공지 알림 | 등록 시 해당 상점을 내 상점에 저장한 구매자 전체에게 안내 생성. 기본 상점 여부와 무관 |
| C08 | 문의 알림 | 새 문의 및 구매자 후속 메시지는 해당 상점 판매자에게, 판매자 답변은 문의 작성자에게 안내 |
| C09 | 예약 정책과 독립 | 문의 작성·답변·댓글은 예약 수량·픽업일·상태를 바꾸지 않음 |
| C10 | 판매자 당일 취소 | 판매자가 유효 예약의 사유를 입력하고 확인하면 당일에도 즉시 취소. 플랫폼 관리자 요청·승인 없음 |

공지 전체 알림은 다른 상점의 구매자나 모든 서비스 회원에게 보내는 것이 아니다. 알림 내역을 생성하되 OS 권한과 서비스 알림 설정을 존중하며 실제 푸시 수신을 보장하지 않는다. 문의는 개인정보가 포함될 수 있으므로 잠금화면 알림에는 본문·연락처를 넣지 않는다.

## 2. 구현 기본안

- 공지 댓글에는 판매자 답글만 지원하고 구매자 간 대댓글은 첫 구현에서 제외한다. 비공개 문의 대화와 구분한다.
- 삭제된 댓글에 다른 사람의 답글이 있으면 원문 대신 ‘삭제된 댓글입니다’를 표시하고 다른 작성자의 글을 임의로 삭제하지 않는다. 이것은 본인 삭제 제한을 의미하지 않는다.
- 공지 삭제 시 일반 조회·신규 댓글을 중단한다. 알림 링크에는 삭제 안내를 표시한다.
- 문의 삭제 시 일반 조회 목록에서 제거한다. 거래 기록 보존이 필요한 경우에만 기존 개인정보 보관 정책에 따라 최소 기록을 분리 보관한다. 본인 정보가 다른 구매자에게 공개되지 않아야 한다.
- 원문을 읽은 뒤 수정된 경우 수정 시각을 표시한다. 요청 재시도는 중복 게시물·메시지·알림을 만들지 않는다.
- 공지 수정·삭제는 새 공지 전체 알림을 재발송하지 않는 기본안. 댓글 알림은 아래 후속 설계에서 정한다.
- 공지 내용은 텍스트로 시작하며 공구 상품과 독립적으로 게시 가능하다.

## 3. 세부 설계·후속 항목

아래 항목은 승인된 기능을 철회하는 미결정 사항이 아니라 별도 합의 또는 구현 설계가 필요한 항목이다.

- 공지 이미지 첨부, 상단 고정, 공구 상품 링크 연결은 선택 기능이며 아직 확정하지 않았다.
- 공지 댓글·판매자 답글에 대한 개별 알림 여부, 알림 설정 세분화.
- 글·댓글 길이, 첨부 형식·크기, 페이지 크기, 수정 이력의 내부 보존 범위.
- 비공개 문의 상태(답변 대기·답변 완료), 추가 질문 후 상태 전환의 UI 설계.
- 판매자 웹 알림 전달 방식(웹 푸시 또는 화면 내 알림). 이메일·카카오 메시지는 자동 추가하지 않는다.
- 삭제·신고·이용 제한 시 자료 보존·플랫폼 관리자 접근 절차. 관리자의 비공개 문의 열람을 기본 허용하지 않는다.

## 4. 검수 기준

1. 다른 구매자가 문의 ID를 직접 요청해도 본문·답변·첨부를 볼 수 없다.
2. 다른 판매자의 상점 공지·댓글 답글·문의에 접근하거나 수정할 수 없다.
3. 자신의 글·댓글은 수정·삭제할 수 있고 다른 작성자의 글은 수정·삭제할 수 없다.
4. 새 공지는 해당 상점 저장 구매자에게만 중복 없이 알림 생성. 기본 상점이 아니어도 대상이다.
5. 문의 답변 알림은 작성자에게만 전달되고 다른 구매자의 알림 내역에 나타나지 않는다.
6. 댓글·문의 작성만으로 예약·수량·픽업일이 변하지 않는다.
7. 판매자 당일 취소는 관리자 승인 없이 즉시 처리하며 사유·알림·수량 반환·이력을 남긴다.
