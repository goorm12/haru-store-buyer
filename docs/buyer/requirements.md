- v1.1 / 2026-10-14
- 구매자 웹·Capacitor 앱 전용. [공통 정책](../common/requirements.md)을 함께 적용한다.

### 2.3 구매자 화면과 기능

| 화면 | 주요 요구사항 |
| --- | --- |
| 로그인·가입 | 카카오 로그인, 약관 동의, 예약 확인용 이름·연락처 입력 |
| 상점 선택·내 상점 | 상점명 검색, 주소 확인, 저장·해제·전환, 기본 상점 지정 |
| 상품 목록 | 선택한 상점의 상품 이미지, 이름, 판매 단위, 가격, 예약 가능 여부 표시 |
| 상품 상세 | 이미지·설명, 가격, 예약 마감, 픽업 가능일, 변경·취소 기준, 상점 위치·연락처 표시, 상점·상품 신고 |
| 예약하기 | 수량·픽업일 선택, 예상 금액 확인, 현장 결제 안내 |
| 예약 완료 | 예약번호, 상품·수량·금액, 픽업일, 상점·주소·운영시간 표시 |
| 내 예약 목록 | 예정된 예약과 지난 예약 조회, 상점·상품·픽업일·상태 표시 |
| 예약 상세 | 예약 정보 확인, 허용 기한 내 수량·픽업일 변경 및 전체 취소 |
| 알림 내역 | 예약·픽업·취소 안내 확인 |
| 내 정보·설정 | 이름·연락처 수정, 알림 설정, 로그아웃, 회원 탈퇴 |

예약 화면은 언제, 어디서, 무엇을, 몇 개, 얼마에 수령하는지 쉽게 보여준다. 연락처는 구매자가 직접 입력하며 휴대폰 인증은 MVP에 포함하지 않는다. 연락처 형식은 검증하지만 실제 소유 여부를 인증한 것으로 표시하지 않는다.


## 공지·문의

공개 공지 조회, 로그인 후 본인 댓글 작성·수정·삭제, 판매자 답글 확인. 문의는 작성자·판매자만 조회하는 비공개 대화이며 본인 문의·메시지 수정·삭제 가능. 새 공지는 저장한 해당 상점 구매자 전체, 문의 답변은 작성자에게 알린다. [확정 정책·설계 항목](../common/communication-policy.md) 참조.
